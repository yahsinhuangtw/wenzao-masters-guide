# The master's timeline

Status of this file: this is a suggested pacing, not a set of Wenzao rules. Rules and exact deadlines live in `calendar-115.md` and the department files. Where a stage has a real rule, the rule is marked `TODO(verify)` until the department confirms it.

The program is usually two years. Use the table to decide what to bring up for a student, based on how long they have been in the program. It is a prompt for the conversation, not a requirement.

| When | What usually needs attention | Wenzao-specific part |
|---|---|---|
| Before classes start | First-round course selection, tuition payment, getting access to the library systems | New-student first round: `2026-08-24` to `2026-08-26`. Tuition: `2026-09-04` |
| First weeks | Add/drop, finding where the information lives, a first look at thesis topics | Second all-school add/drop: `2026-09-07` to `2026-09-14` |
| First semester | Narrow a topic, read past theses, shortlist faculty | Thesis workflow: `thesis-and-advisor.md` |
| End of first semester | Course selection for semester 2, talk to a possible advisor | Semester 2 first round: `2026-12-21` to `2026-12-24` |
| First year, second semester | Settle on an advisor, draft a proposal outline | Application deadline in the calendar: `2027-07-09`. The department's own proposal timing is `TODO(verify)` |
| Second year | Proposal approved, thesis writing, apply for the oral exam | Application deadlines: `2027-01-08` and `2027-07-09` |
| Final semester | Oral exam, final copy, exit procedures | DIA has checklists for finalized copy and leaving school (`departments/dia.md`). GIES: `TODO(verify)` |
| Graduation | Degree certificates, ceremony | Calendar: `2027-05-29` ceremony, `2027-07-02` degree certificates (for this academic year) |

## Using it in a conversation

1. Ask how long the student has been in the program.
2. Find the row, mention the one or two items that fit, and ask whether they want details.
3. Offer the calendar file so the dates arrive in their phone and don't depend on their remembering to ask.
